# Sources

This repository is Moayad Alshehri's adaptation of the Qafila gross margin project
from **SDAIA Academy (Sidai Academy)**.

The assignment, synthetic data generator, dependency environment, and contract
checker come from [SDAIAAcademy/qafila-margin-project](https://github.com/SDAIAAcademy/qafila-margin-project).

The following examples were reviewed, with permission to reuse them provided by
the repository owner:

- [reem7628-blip/project](https://github.com/reem7628-blip/project), commit `2713e9606bb783e61ecef644d7107b5482c93644`.
  The pipeline, dbt models and tests, and inspection/reference tools are adapted
  from this example.
- [dee2002al-c/qafila-margin-project](https://github.com/dee2002al-c/qafila-margin-project),
  commit `c3f7e86790dfd192dc7fc8208cc4d322cb3c2f89`.
- [ariffalshehri/qafila-margin-project](https://github.com/ariffalshehri/qafila-margin-project),
  commit `2d636ee619a1dfe80407525b59f6a4b5fd0d41f7`.

The additions here include preservation of original cost text, current dbt test
argument syntax, an automated verification of re-runs and correction snapshots,
and documentation with results measured in this repository.
